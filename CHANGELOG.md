# Changelog

## 1.0.0

Первый стабильный выпуск.

- Страницы в Markdown и MDX: CommonMark, GFM, сноски, HTML, эмодзи, KaTeX, Mermaid.
- Компоненты: выноски, вкладки, шаги, карточки, раскрывающиеся блоки. Свои компоненты подключаются из `components/`.
- Подсветка кода Shiki при сборке: заголовки, номера строк, диффы, фокус, вкладки.
- Сайдбар из структуры папок и `meta.json`, оглавление, хлебные крошки.
- Поиск по всем разделам без сервера.
- Копирование страницы в Markdown, просмотр исходника и вопросы к ChatGPT, Claude, Perplexity.
- Светлая и тёмная темы, цвета и шрифты в `theme.css`.
- Настройки и тексты интерфейса в `wiki.config.ts`.
- Пакет `@opensd/create-wiki`: новая вики через `pnpm create @opensd/wiki`, обновление ядра через `upgrade`.
