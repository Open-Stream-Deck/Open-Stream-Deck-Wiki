## GitHub Alerts

Тот же синтаксис, что на GitHub, поэтому файлы выглядят одинаково и там, и здесь.

```md
> [!NOTE]
> Полезная информация.
```

> [!NOTE]
> Полезная информация, которую стоит знать даже при беглом чтении.

> [!TIP]
> Совет, который упростит работу.

> [!IMPORTANT]
> Ключевая информация для достижения цели.

> [!WARNING]
> Срочное: требует немедленного внимания.

> [!CAUTION]
> Возможные негативные последствия действия.

Можно задать свой заголовок прямо после типа:

> [!TIP] Горячая клавиша
> Поиск открывается по <kbd>Ctrl</kbd> + <kbd>K</kbd> или <kbd>/</kbd>.

## Директивы

Блоки через `:::` удобны, когда внутри много разметки. Заголовок указывается в квадратных скобках.

```md
:::warning[Перед обновлением]
Закоммитьте свои изменения **до** обновления ядра.
:::
```

:::warning[Перед обновлением]
Закоммитьте свои изменения **до** обновления ядра.

- Проверьте, что `pnpm build` проходит
- Прочитайте описание релиза
:::

:::info
Типы: `note`, `info`, `tip`, `success`, `important`, `warning`, `caution`, `danger`.
:::

## Раскрывающийся блок

```md
:::details[Показать подробности]
Скрытое содержимое.
:::
```

:::details[Показать подробности]
Скрытое содержимое с **разметкой** и кодом:

```json
{ "title": "Руководства", "defaultOpen": true }
```
:::

## Шаги

```md
:::steps
### Установите зависимости
Текст шага.

### Запустите
Текст шага.
:::
```

:::steps
### Установите зависимости

`pnpm install` в корне проекта.

### Запустите

`pnpm dev` поднимет вики на `localhost:3000`.
:::

## Вкладки

```md
::::tabs{id="pm"}
:::tab[pnpm]
Содержимое вкладки.
:::
::::
```

::::tabs{id="pm"}
:::tab[pnpm]
Установка через `pnpm add`, запуск через `pnpm dev`.
:::

:::tab[npm]
Установка через `npm install`, запуск через `npm run dev`.
:::

:::tab[yarn]
Установка через `yarn add`, запуск через `yarn dev`.
:::
::::

Вкладки с одинаковым `id` синхронизируются между собой и запоминают выбор.
