Страницы лежат в `content/docs` и пишутся в `.md` или `.mdx`. В `.md` работает чистый Markdown с HTML, в `.mdx` дополнительно доступны React-компоненты.

## Заголовки {#headings}

```md
## Второй уровень
### Третий уровень
#### Четвёртый уровень
## Заголовок со своим якорем {#custom-id}
```

Заголовки второго, третьего и четвёртого уровня попадают в оглавление справа. Якорь генерируется автоматически, в том числе для кириллицы, или задаётся вручную через `{#id}`.

## HTML

В `.md` можно писать любой HTML:

<details>
<summary>Нажмите, чтобы раскрыть</summary>

Внутри `<details>` работает Markdown, если отделить его пустой строкой.

```ts
const answer = 42
```

</details>

<div align="center">
  <sub>Блок, выровненный по центру</sub>
</div>
