Компоненты доступны глобально, импортировать их не нужно. Список лежит в `src/components/mdx/index.tsx`, туда же добавляются свои.

## Details

<Details summary="Можно ли использовать HTML-комментарии в MDX?">
  Нет. В MDX вместо них используются комментарии в фигурных скобках со звёздочками, как в JSX.
</Details>

## Выражения

В MDX работают JavaScript-выражения: сегодня {new Date().getFullYear()} год, а 2 + 2 = {2 + 2}.

## Свой компонент

Свои компоненты лежат в папке `components` в корне проекта. Создайте файл и добавьте компонент в список.

```tsx title="components/badge.tsx"
export function Badge({ children }: { children: React.ReactNode }) {
  return <span className="rounded-md border px-1.5 py-0.5 text-xs">{children}</span>
}
```

```tsx title="components/index.tsx"
import type { MDXComponents } from 'mdx/types'
import { Badge } from './badge' // [!code ++]

export const components: MDXComponents = {
  Badge, // [!code ++]
}
```

После этого `<Badge>Новое</Badge>` работает в любом `.mdx` файле. Компонент с тем же именем, что и встроенный, заменяет встроенный.
