## Новая страница

Создайте файл в `content/docs`, и он сразу появится в сайдбаре и в поиске.

```md title="content/docs/install.md"
---
title: Установка
description: Короткое описание под заголовком и в метаданных
---

Текст страницы.
```

Адрес страницы повторяет путь к файлу: `content/docs/install.md` откроется по `/docs/install`.

## Frontmatter

| Поле          | Что делает                                              |
| ------------- | ------------------------------------------------------- |
| `title`       | Заголовок страницы и пункта в сайдбаре                  |
| `description` | Подзаголовок, описание для поиска и метатегов           |
| `toc`         | `false` скрывает оглавление справа                      |

Если `title` не задан, берётся первый заголовок `#` в файле. Если нет и его, используется имя файла.

## Разделы

Папка становится разделом в сайдбаре. Файл `index.md` внутри открывается по адресу самой папки, а клик по названию раздела ведёт на него.

```
content/docs/
  guides/
    index.md       /docs/guides
    deploy.md      /docs/guides/deploy
```

Порядок страниц, разделители и заголовки разделов задаются в `meta.json`, об этом на странице [Навигация](../configuration/navigation.md).

## .md или .mdx

- `.md` для обычных страниц. Можно писать любой HTML.
- `.mdx` когда нужны [компоненты](../markdown/components.mdx) или JavaScript-выражения.

> [!NOTE]
> Файлы и папки, имя которых начинается с `_` или `.`, не попадают на сайт. Удобно для черновиков.
