---
title: Быстрый старт
description: От одной команды до работающей вики.
---

## Что понадобится

| Инструмент | Версия      |
| ---------- | ----------- |
| Node.js    | 20.9 и выше |
| pnpm       | 12          |

:::steps
### Создайте проект

```bash tab="pnpm"
pnpm create @opensd/wiki my-wiki
```

```bash tab="npm"
npm create @opensd/wiki my-wiki
```

Команда спросит название и описание, скопирует проект в папку `my-wiki` и установит зависимости.

### Запустите dev-сервер

```bash
cd my-wiki
pnpm dev
```

Вики откроется на `http://localhost:3000`. Изменения в страницах видны после обновления вкладки.

### Настройте под себя

Название, ссылки и тексты интерфейса лежат в `wiki.config.ts`, цвета и шрифты в `theme.css`. Подробно об этом в разделе [Настройка](../configuration/index.md).
:::

## Сборка

```bash
pnpm build
pnpm start
```

`build` заранее собирает все страницы, поисковый индекс и исходники для ИИ. `start` запускает готовый сайт.

> [!TIP]
> Перед коммитом полезно прогнать те же проверки, что и CI: `pnpm format:check`, `pnpm typecheck` и `pnpm build`.
