## Что внутри

- **Markdown целиком.** CommonMark, GFM, сноски, HTML, эмодзи, формулы KaTeX и диаграммы Mermaid.
- **MDX.** React-компоненты прямо в тексте: выноски, вкладки, шаги, карточки.
- **Подсветка кода.** Shiki на этапе сборки: заголовки, номера строк, диффы, фокус, вкладки.
- **Навигация.** Сайдбар строится из папок, порядок задаётся в `meta.json`. Оглавление следит за прокруткой.
- **Поиск.** Мгновенный поиск по всем разделам, открывается по <kbd>Ctrl</kbd> + <kbd>K</kbd>.
- **Темы.** Светлая и тёмная, все цвета в CSS-переменных.
- **Для ИИ.** Каждую страницу можно скопировать как Markdown или открыть в ChatGPT, Claude и Perplexity.
- **Статика.** Все страницы собираются заранее и открываются мгновенно.

## Стек

Next.js 16, React 19, TypeScript, Tailwind CSS 4, Motion, MDX 3, Shiki, KaTeX, Mermaid, MiniSearch.

</Callout>
