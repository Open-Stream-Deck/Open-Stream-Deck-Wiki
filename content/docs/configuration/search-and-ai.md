## Поиск

Поиск работает без сервера. При сборке все страницы разбиваются на разделы по заголовкам второго и третьего уровня, индекс отдаётся по `/api/search`, а ищет уже браузер.

- Открыть: <kbd>Ctrl</kbd> + <kbd>K</kbd>, <kbd>⌘</kbd> + <kbd>K</kbd> или <kbd>/</kbd>.
- Выбрать результат: стрелки и <kbd>Enter</kbd>.
- Ищет по началу слова и прощает опечатки.

Результат ведёт прямо к нужному разделу страницы.

## Действия на странице

Под заголовком каждой страницы есть кнопки для работы с ИИ.

```ts title="wiki.config.ts"
pageActions: {
  copyMarkdown: true,
  viewMarkdown: true,
  ai: ['chatgpt', 'claude', 'perplexity'],
}
```

| Поле           | Что делает                                       |
| -------------- | ------------------------------------------------ |
| `copyMarkdown` | Кнопка «Скопировать Markdown»                    |
| `viewMarkdown` | Пункт «Открыть как Markdown» в меню              |
| `ai`           | Ассистенты в меню «Спросить ИИ». `[]` убирает их |

Если выключить всё, блок с кнопками пропадает.

## Исходники страниц

Исходник любой страницы доступен по адресу `/raw/` плюс путь страницы:

```
/docs/getting-started   ->   /raw/docs/getting-started
```

Именно эту ссылку получает ассистент. Текст запроса лежит в `ui.askAIPrompt`, `{url}` в нём заменяется на ссылку.

> [!IMPORTANT]
> Ассистент должен иметь доступ к сайту. Пока вики работает на `localhost`, ссылку он не откроет. После деплоя пропишите настоящий адрес в `NEXT_PUBLIC_SITE_URL`.
