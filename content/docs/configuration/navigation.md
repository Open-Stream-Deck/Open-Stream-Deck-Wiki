## meta.json

В каждой папке может лежать `meta.json`. Без него страницы идут по алфавиту, а `index` первым.

```json title="content/docs/guides/meta.json"
{
  "title": "Руководства",
  "description": "Текст для карточки раздела на главной",
  "defaultOpen": true,
  "pages": ["index", "---Основы---", "install", "configure", "..."]
}
```

| Поле          | Что делает                                                   |
| ------------- | ------------------------------------------------------------ |
| `title`       | Название раздела в сайдбаре                                  |
| `description` | Описание в карточке раздела на главной                       |
| `defaultOpen` | Раскрыть раздел в сайдбаре сразу                             |
| `pages`       | Порядок страниц и вложенных папок, по имени без расширения   |

В `pages` есть два особых значения:

- `---Текст---` добавляет подпись-разделитель;
- `...` подставляет все страницы, которые не перечислены явно.

Если `...` нет, неперечисленные страницы добавляются в конец.

## Меню в шапке

```ts title="wiki.config.ts"
nav: [
  { title: 'Документация', page: '' },
  { title: 'Markdown', page: 'markdown' },
  { title: 'Блог', href: 'https://example.com/blog' },
]
```

`page` указывается относительно документации, `href` подходит для любой ссылки.

## Карточки на главной

Главная показывает карточку на каждый раздел верхнего уровня. Описание берётся из `description` в `meta.json`, затем из описания `index.md` раздела. Если нет обоих, выводится число страниц.

## Хлебные крошки и пагинация

Строятся автоматически из дерева разделов. Кнопки «Назад» и «Далее» внизу идут в том же порядке, что и сайдбар.
