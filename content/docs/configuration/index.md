## Основное

```ts title="wiki.config.ts"
const config: WikiConfig = {
  name: 'My Project',
  title: 'My Project Docs',
  description: 'Документация моего проекта.',
  url: process.env.NEXT_PUBLIC_SITE_URL ?? 'http://localhost:3000',
  locale: 'ru',
  home: true,
  docsRoute: '/docs',
  github: 'https://github.com/me/my-project',
  editUrl: 'https://github.com/me/my-project/edit/main/content/docs',
  codeThemes: { light: 'vitesse-light', dark: 'vitesse-dark' },
}
```

| Поле          | Что делает                                                              |
| ------------- | ----------------------------------------------------------------------- |
| `name`        | Название в логотипе. Первое слово выделяется жирным                     |
| `title`       | Заголовок главной и суффикс во вкладке браузера                         |
| `description` | Подзаголовок главной и описание сайта                                   |
| `url`         | Адрес сайта для метатегов и ссылок для ИИ                               |
| `locale`      | Язык страницы и сортировки                                              |
| `home`        | Показывать главную страницу                                             |
| `docsRoute`   | Адрес документации                                                      |
| `github`      | Ссылка на репозиторий в шапке и на главной. Уберите поле, чтобы скрыть  |
| `editUrl`     | Начало ссылки «Редактировать на GitHub». Без поля кнопка не показывается |
| `codeThemes`  | Темы подсветки кода, подробнее в [Оформлении](./theming.md)             |

## Маршруты

| `home`  | `docsRoute` | Результат                                       |
| ------- | ----------- | ----------------------------------------------- |
| `true`  | `'/docs'`   | Главная на `/`, документация на `/docs`         |
| `false` | `'/docs'`   | `/` перенаправляет на `/docs`                   |
| любое   | `'/'`       | Документация прямо с корня, главной нет         |

Адрес может быть любым: `'/wiki'`, `'/help'`. Ссылки в контенте пишутся путями к файлам, поэтому смена адреса ничего не ломает.

## Тексты интерфейса

Все надписи интерфейса лежат в `ui`: кнопки, подсказки поиска, названия выносок. Чтобы перевести вики на другой язык, достаточно поменять их и `locale`.

```ts
ui: {
  search: 'Search',
  onThisPage: 'On this page',
}
```

Меню в шапке и действия на странице описаны в [Навигации](./navigation.md) и [Поиске и ИИ](./search-and-ai.md).
